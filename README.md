# Creative Automation Race

Onepager voor de eerstejaars Digitale Vormgeving (Artevelde Hogeschool) over het vak Creative Automation, gemaakt als racespel in neonstijl.

Rij met je auto langs vijf pitstops. Bij elke pitstop tank je 8 seconden en lees je een hoofdstuk van het vak. Verzamel onderweg jerrycans en rij naar de finish.

## Besturing

- Muis: de auto volgt je muis
- Gsm: houd je vinger op het scherm
- Toetsen: Z of W (gas), Q of A (links), S (rem), D (rechts), of de pijltjestoetsen

## Techniek

- Puur HTML, CSS en JavaScript (canvas), geen framework
- Werkt op desktop en gsm, respecteert "reduced motion"
- AI-beelden per pitstop gemaakt met Weave
- Gemaakt met Claude Code en de skills frontend-design, web-design-guidelines en webapp-testing
